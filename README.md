# Добро пожаловать в мой учебный проект автотестов Playwright

Этот репозиторий - результат моей практики по созданию UI-автотестов на **Playwright**.  
Здесь я учусь строить гибкую архитектуру автотестов, писать чистый код и выносить повторяемую логику в отдельные компоненты.

## Что реализовано в проекте

### Виджеты (Widgets)
Я выделил повторяющиеся элементы интерфейса (карточки задач, формы, таблицы, тулбары с действиями) в независимые **виджеты** - мини-компоненты, инкапсулирующие локаторы и логику работы с ними.  
Это помогает:
- писать более читаемые тесты,
- переиспользовать элементы интерфейса,
- упрощать поддержку проекта.

### Page Object Model (POM)
Для каждой ключевой страницы создан отдельный класс.  
PO содержит:
- базовые селекторы,
- методы действий,
- фабрики виджетов (например `getTaskCardByText()`).

### Авторизация и фикстуры
Реализована конфигурация Playwright с фикстурой `autoLogin`, которую можно гибко включать и отключать в конкретных тестах через `test.use({ autoLogin: ... })`.

### UI-тесты
Тесты проверяют:
- авторизацию и разлогин,
- работу с карточками задач,
- взаимодействие с формами,
- работу дропдаунов, таблиц и кнопок действий.

## Зачем этот проект
Это тренировочная площадка, где я отрабатывал:

## Как запустить приложение и прогнать тесты

### 1) Установить зависимости
```bash
npm ci
```

### 2) Установить браузер для Playwright
```bash
npx playwright install chromium
```

### 3) Запустить приложение
```bash
npm run dev
```

После запуска приложение будет доступно по адресу: `http://localhost:5173`.

### 4) Прогнать автотесты
В новом терминале (не останавливая `npm run dev`) выполните:
```bash
npx playwright test
```

### Полезные команды
- Запустить тесты в UI-режиме:
```bash
npx playwright test --ui
```
- Открыть HTML-отчёт после прогона:
```bash
npx playwright show-report
```
